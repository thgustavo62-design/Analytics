PASTA DE ENTRADA — Vermelhinha Analytics
=========================================

Jogue os arquivos aqui. O site percebe sozinho e atualiza o painel — não precisa
abrir nada, nem clicar em "enviar".

O QUE JOGAR
-----------
1) Relatorio "Analitico de Vendas" (PDF)
   - Exporte do sistema da farmacia (o mesmo relatorio de sempre).
   - Pode ser o mes inteiro OU o mes-ate-hoje (para acompanhar o dia a dia).
   - Nao precisa dizer de qual loja e: o site le o CNPJ no cabecalho e descobre
     se e Minas Farma ou Farma e Farma.
   - Se a soma nao bater com o "Total:" impresso no rodape, o arquivo e RECUSADO
     (aparece no log em "Entrada de arquivos") e o painel antigo continua no ar.

2) Coleta de concorrentes (Concorrentes_Coleta_AAAA-MM-DD.xlsx)
   - Formato de 36 colunas de sempre.
   - Vale para as duas lojas (cada uma comparada com o proprio preco).
   - O mes vem da data no nome do arquivo.

2b) Estoque (xlsx do sistema — "Posicao de estoque" / export geral)
   - Nome do arquivo PRECISA conter "estoque" (ou "estoqeu") E dizer a loja:
     "minas" ou "farma e farma".  Ex.: "estoque minas farma.xlsx".
     Se for o export unico da rede toda, use "estoque geral.xlsx" (aplica nas 2).
   - Um arquivo so ja alimenta estoque + preco de venda + preco de promocao +
     custo (coluna "Ult. Prc. Entrada"), tudo do mesmo xlsx.
   - Isso libera: days-of-cover, margem %, risco de ruptura, capital parado e o
     simulador de oferta com margem/estoque reais.
   - Pode mandar todo dia/semana; cada envio vira um snapshot novo (historico).

3) (opcional) Instagram em JSON
   - Nome do arquivo com "instagram" (ex.: instagram-minas-2026-08.json)
   - Conteudo: { "loja": "Minas Farma", "periodo": "2026-08",
                 "metricas": { "visualizacoes": {"valor":"414,3 mil","delta":"112,0"}, ... } }
   - Sem isso, use o formulario em Upload de dados.

4) (Fase 2) Analise Comercial em JSON
   - Qualquer .json cujo conteudo tenha "meta" + "diagnostico_executivo".
   - Gerado por fora (tarefa agendada que aplica o prompt em
     prompts/motor-analise-comercial.md). Vai para a tela "Analise Comercial".
   - Se nao passar na validacao, e recusado e a analise anterior fica no ar.

COPIA ESTATICA (site "publicavel")
----------------------------------
- A cada arquivo processado, o servidor regenera uma copia estatica em
  C:\Sistema Marketing\publico\  (index.html + uma pagina por loja, com Painel +
  Marketing + Intelligence "assados" dentro do HTML — abrem sem servidor).
- Preview local: http://localhost:4180/publico/  (sem senha).
- Para deixar "disponivel" de verdade: aponte a variavel de ambiente
  VA_PUBLIC_DIR para uma pasta do OneDrive / Google Drive / GitHub Pages /
  Netlify.  O link publico passa a se atualizar sozinho, sem expor o servidor.
- Forcar agora: botao nao tem — use  POST /api/publicar  (logado).

DICAS
-----
- Pode deixar os arquivos aqui depois de processados; o site nao reprocessa o
  mesmo arquivo (a menos que ele mude).
- Um PDF que cobre varios meses vira um painel por mes automaticamente.
- Para exportar o "Analitico de Vendas" todo dia sem pensar, crie uma Tarefa
  Agendada do Windows que salve o arquivo direto nesta pasta.
